Use the API

One GET endpoint returns a random quote as JSON. CORS is enabled, so you can call it straight from the browser.

GET https://calandhobbes-quoter.vercel.app/api/quotes/random

Fetch a quote with plain JavaScript:

const res = await fetch('https://calandhobbes-quoter.vercel.app/api/quotes/random');
const data = await res.json();
console.log(data);

A reusable hook that fetches from any endpoint:

import { useState, useEffect } from 'react';

const useRandomData = (apiEndpoint) => {
  const [data, setData] = useState({});

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(apiEndpoint);
        setData(await response.json());
      } catch (error) {
        console.error('Error fetching data:', error);
      }
    };
    fetchData();
  }, [apiEndpoint]);

  return data;
};

Clone the repo and start the Flask server:

git clone https://github.com/bhavv04/calandhobbes-quoter
cd calandhobbes-quoter
pip install -r requirements.txt
python api.py

Then open http://127.0.0.1:8080/api/quotes/random.
